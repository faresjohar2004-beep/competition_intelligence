# PART 1 — FULL PRODUCT BASELINE

## 1. What Astra OS Is

A daily habit/identity-change web + native-mobile application, gated behind Clerk authentication, built around a promise → action → evidence → score → streak core loop. Wrapped around that loop: an AI coach with live user-context injection, AI-attempted daily missions (with deterministic fallback), nominally-AI future-self letters and biography entries (confirmed: template-random, zero model calls), a deterministic "AI Projection" of future-self scores, an unlockable life-chapter system, a loss-aversion "Hall of Regret" / Courage Challenge mechanic, and Stripe-billed Pro tier. Positioned explicitly as "An OS for identity change," not a task manager (`Landing.tsx:253-260`).

## 2. Core User Journey

Landing page → 3-question guest onboarding → Clerk signup with auto-resumed onboarding answers → pre-seeded Dashboard/Home → daily loop (make/keep promise, log action, build evidence, reflect), with secondary navigation into Missions, Life Scores, Letters, Biography, Timeline, Hall of Regret, Chapters. Mobile mirrors this across 5 tabs: Home, Actions, Missions, Coach, Profile (Coach confirmed as its own full-screen chat UI, `artifacts/astra-mobile/app/(tabs)/coach.tsx`, 335 lines, not a "Life Scores" tab as previously implied).

## 3. Time to Value

**NOT_INSPECTED this run** — no live/browser access to the gated SPA exists in this environment (Clerk-gated, no browser-automation tool available), so actual onboarding-to-first-value latency cannot be timed empirically. Code-level evidence (3-question onboarding, pre-seeded dashboard) suggests a short nominal path, but this is inferred from code structure, not observed behavior. Flagged UNKNOWN for empirical confirmation.

## 4. Product Clarity

Strong at the top: "Not a task manager. An OS for identity change" (`Landing.tsx:253-260`) is a clear, differentiated one-line positioning. Clarity degrades once inside the product: the Dashboard stacks ~15 full-width sections (daily ritual + exploration content) with a labeled divider ("Explore Your Journey," `Dashboard.tsx:~2764-2770`, confirmed present again this week) separating macro zones, but no sub-hierarchy within the 15-card ritual zone itself. Four features market themselves as "AI" (Missions, Letters, Biography, Future Self Projection) while only two (Coach, Missions-with-fallback) actually invoke a model — this is a clarity/trust problem, not just a labeling nitpick, now confirmed to extend into paid-feature marketing copy (see Differentiation section).

## 5. Positioning Audit

Marketing claim: "An OS for identity change" / "Astra OS helps you become someone" (`Landing.tsx:253-260`). This positioning is **substantively earned** by the real identity mechanics (Evidence Vault, real identity statements, real promise/streak loop, real AI coach). It is **partially undermined** by: (a) narrative-content features (Letters, Biography) marketed as AI-authored but template-randomized, (b) the "Hall of Regret" accountability mechanic presenting an uncalibrated flat-multiplier stat as a precise, personalized number, (c) multiple unsourced "research shows"/percentile claims used as motivational copy (Dashboard.tsx:182, 196, 225, 1311, 1770) with no citation or data source — these function as fabricated social proof.
