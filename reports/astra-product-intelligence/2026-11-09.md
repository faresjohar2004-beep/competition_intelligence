# PART 1 — FULL PRODUCT BASELINE

## 1. What Astra OS Is

A daily habit/identity-change web + native-mobile application, gated behind Clerk authentication, built around a promise → action → evidence → score → streak core loop. Wrapped around that loop: an AI coach with live user-context injection, AI-attempted daily missions (with deterministic fallback), nominally-AI future-self letters and biography entries (confirmed: template-random, zero model calls), a deterministic "AI Projection" of future-self scores, an unlockable life-chapter system, a loss-aversion "Hall of Regret" / Courage Challenge mechanic, and Stripe-billed Pro tier. Positioned explicitly as "An OS for identity change," not a task manager (`Landing.tsx:253-260`). No change from last week (code unchanged).

## 2. Core User Journey

Landing page → 3-question guest onboarding → Clerk signup with auto-resumed onboarding answers → pre-seeded Dashboard/Home → daily loop (make/keep promise, log action, build evidence, reflect), with secondary navigation into Missions, Life Scores, Letters, Biography, Timeline, Hall of Regret, Chapters. Mobile mirrors this across 5 tabs: Home, Actions, Missions, Coach, Profile. No change from last week.
